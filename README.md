# HTML Resume Page

A simple resume webpage created using HTML.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-html-resume`

## File Name

`resume.html`

## Description

This project demonstrates how to create a basic resume webpage using HTML. It contains personal information, career objective, education, technical skills, projects, strengths, hobbies, and declaration.

## Features

* Personal information
* Career objective
* Education details
* Technical skills
* Project details
* Strengths
* Hobbies
* Declaration

## Requirements

* Any modern web browser such as Chrome, Firefox, or Edge

## How to Run

1. Save the code as `resume.html`.
2. Open the file in a web browser.
3. The resume page will be displayed.
